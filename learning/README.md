## 学完后你能掌握什么？

学完 **00–09 + 项目总览** 后，你会对下面这些有清晰概念，并能跑通、讲清主流程和证据点：

| 概念 | 学习文档里学到什么 |
|------|-------------------|
| **智能合约** | 是什么、怎么执行、本项目用到的 Solidity/OZ（00、01）；池子合约 supply/borrow/repay/withdraw 逐函数（02）。 |
| **池子（借贷合约）** | 单币种借贷、LTV=75%、四动作、健康因子、事件（00、01、02）；前端 ABI 名 SimpleLending，实现是 LendingPoolImpl。 |
| **治理与治理币** | v1.0 含 Governor + Timelock + 治理币（00 §5）；治理页用 getDeployments + GovernorP9/GovToken 读提案/投票（02、07）；需先 `deploy:p9` 治理页才有数据。 |
| **预言机 / 清算 / Treasury** | 00 §5、02 Part IV 提到在总览 §4；具体设计在 [docs/12-PROTOCOL-DESIGN](../docs/12-PROTOCOL-DESIGN.md)。 |
| **前端怎么连** | 读写分离、getContracts/getDeployments、事件刷新、交易状态机、预确认（02、03、04、07）。 |

**想「完全吃透」**（池子配置、LTV 谁设、治理币怎么投票、清算怎么触发等）：请接着看 [项目总览架构](项目总览架构.md) §3–§5 的表格与列表，并对照 `contracts/`、`frontend/src/` 和 [docs/12-PROTOCOL-DESIGN](../docs/12-PROTOCOL-DESIGN.md)、[docs/15-governance-create-proposal-example](../docs/15-governance-create-proposal-example.md)。学习文档是**主线+索引**，总览和代码是**完整图景**。
