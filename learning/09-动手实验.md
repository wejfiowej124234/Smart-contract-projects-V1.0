## 第一步：安装基础软件

### 1.1 安装 Node.js

**检查是否已安装**：
```bash
node --version
# 如果显示 v18.x.x 或更高，跳过此步骤
```

**安装步骤**（如果未安装）：
1. 访问 https://nodejs.org/
2. 下载 LTS 版本（长期支持版）
3. 双击安装包，一路下一步
4. 重启命令行，运行 `node --version` 验证

### 1.2 安装 Git

**检查是否已安装**：
```bash
git --version
# 如果显示 git version x.x.x，跳过此步骤
```

**安装步骤**（如果未安装）：
1. 访问 https://git-scm.com/
2. 下载对应操作系统的版本
3. 安装时全部默认选项即可

### 1.3 安装 VS Code

1. 访问 https://code.visualstudio.com/
2. 下载安装
3. 推荐安装插件：
   - Solidity（作者：Juan Blanco）
   - ESLint
   - Prettier

### 1.4 安装 MetaMask

1. 在 Chrome 浏览器中访问：
   https://metamask.io/download/
2. 点击"Install MetaMask for Chrome"
3. 添加到 Chrome
4. 如果是第一次使用：
   - 选择"创建新钱包"
   - 设置密码（务必记住！）
   - 保存助记词（写在纸上！）

**⚠️ 重要提示**：
- 助记词是恢复钱包的唯一方式，务必保管好
- 这是测试钱包，不要存入真实资产
- 永远不要分享助记词给任何人

## 第四步：启动本地区块链

### 4.1 打开第一个终端，启动 Hardhat 本地链

```bash
npx hardhat node
```

**预期输出**：
```
Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/

Accounts
========
Account #0: 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 (10000 ETH)
Private Key: 0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80

Account #1: 0x70997970C51812dc3A010C7d01b50e0d17dc79C8 (10000 ETH)
...
```

**⚠️ 重要**：
- 这个终端要**一直开着**，不要关闭
- 这是模拟的区块链，每次重启数据会重置
- Account #0 是默认的部署账号

### 4.2 常见问题

**问题**：端口 8545 被占用
```
Error: listen EADDRINUSE: address already in use :::8545
```

**解决**：
```bash
# Windows: 查找占用端口的进程
netstat -ano | findstr :8545
# 记下 PID，然后结束进程
taskkill /PID <PID> /F

# Mac/Linux:
lsof -i :8545
kill -9 <PID>
```

## 第六步：配置 MetaMask

### 6.1 添加本地网络

1. 打开 MetaMask
2. 点击顶部网络下拉菜单
3. 点击"添加网络"
4. 点击"手动添加网络"
5. 填入以下信息：

```
网络名称：Hardhat Local
新 RPC URL：http://127.0.0.1:8545
链 ID：31337
货币符号：ETH
```

6. 点击"保存"

### 6.2 导入测试账号

**方法 1：使用 Hardhat 默认账号（推荐新手）**

1. MetaMask → 点击账号头像 → 导入账号
2. 选择类型：私钥
3. 粘贴私钥：
   ```
   0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80
   ```
4. 点击"导入"
5. 重命名为"Hardhat Account #0"

**⚠️ 提示**：这是公开的测试私钥，只用于本地测试！

**方法 2：使用自己的账号（需要 seed）**

如果你想用自己的 MetaMask 账号：

1. 复制你的账号地址（点击账号名复制）
2. 在终端运行：
   ```bash
   SEED_ADDRESS=<你的地址> npx hardhat run scripts/deploy.ts --network localhost
   ```
3. 这会给你的账号转 10000 USD8

### 6.3 验证余额

1. 确保 MetaMask 连接到"Hardhat Local"网络
2. 应该看到 10000 ETH（测试币）
3. 点击"导入代币"
4. 粘贴 USD8 合约地址（从部署输出复制）
5. 应该看到 10000 USD8

## 第八步：完整操作流程

### 8.1 连接钱包

1. 点击页面上的"Connect Wallet"按钮
2. MetaMask 会弹出，选择账号
3. 点击"下一步" → "连接"
4. 页面应该显示：
   - 你的地址（前 6 位和后 4 位）
   - 链 ID：31337
   - 余额信息

**如果出现"Wrong Network"**：
- 点击页面上的"Switch to Hardhat Local"
- MetaMask 会提示切换网络
- 批准即可

### 8.2 存款（Supply）

1. 在"Supply"栏输入金额，例如：`100`
2. 点击"Supply"按钮
3. 会显示需要 Approve（授权）
4. MetaMask 弹出，点击"确认"（这是授权交易）
5. 等待确认（通常很快）
6. 再次点击"Supply"
7. MetaMask 弹出，点击"确认"（这是存款交易）
8. 观察页面：
   - 状态显示：Signing... → Pending... → Confirmed!
   - 仪表盘自动更新（不需要刷新页面）
   - "Your Supplied"显示 100 USD8

### 8.3 借款（Borrow）

1. 检查"Max Borrow"：应该是 75 USD8（100 * 75%）
2. 在"Borrow"栏输入金额，例如：`50`
3. 点击"Borrow"按钮
4. MetaMask 确认
5. 观察：
   - "Your Borrowed"显示 50 USD8
   - "Health Factor"显示 150%
   - USD8 余额增加 50

### 8.4 还款（Repay）

1. 在"Repay"栏输入金额，例如：`30`
2. 点击"Repay"按钮
3. 会需要先 Approve（如果之前没授权）
4. 确认授权 → 确认还款
5. 观察：
   - "Your Borrowed"变成 20 USD8
   - "Health Factor"提高到 375%

### 8.5 取款（Withdraw）

1. 检查"Max Withdraw"（考虑健康因子限制）
2. 在"Withdraw"栏输入金额
3. 点击"Withdraw"按钮
4. MetaMask 确认
5. 观察余额变化

**⚠️ 注意**：
- 如果借款太多，可能无法取款全部（会提示健康因子不足）
- 必须先还款才能取出更多

## 常见问题排查

### ❌ 问题 1：MetaMask 显示"Internal JSON-RPC error"

**原因**：
- 本地链重启了，但 MetaMask 还记得旧的交易 nonce

**解决**：
1. MetaMask → 设置 → 高级 → 重置账户
2. 确认重置
3. 刷新页面

### ❌ 问题 2：合约调用失败"nonce too low"

**原因**：同上

**解决**：重置 MetaMask 账户

### ❌ 问题 3：页面一直显示"Loading..."

**检查**：
1. 本地链是否在运行？
   ```bash
   curl http://localhost:8545
   # 应该返回一些 JSON
   ```
2. 合约是否部署？
   ```bash
   cat deployments/31337.json
   # 应该有内容
   ```
3. 浏览器控制台有无错误？
   - F12 打开开发者工具
   - 切换到 Console 标签
   - 看是否有红色错误

### ❌ 问题 4：交易一直 Pending

**可能原因**：
1. MetaMask 没连接到正确的网络
   - 检查 MetaMask 顶部是否显示"Hardhat Local"
2. 本地链停止了
   - 检查第一个终端是否还在运行

### ❌ 问题 5："Insufficient gas"

**原因**：
- 账户 ETH 不足（虽然有 10000 但可能被其他交易消耗了）

**解决**：
- 重启本地链（会重置余额）
- 或者导入另一个 Hardhat 默认账号

## 重启流程（后续使用）

每次使用只需要这三步：

```bash
# Terminal 1: 启动本地链
npx hardhat node

# Terminal 2: 部署合约
npx hardhat run scripts/deploy.ts --network localhost

# Terminal 3: 启动前端
cd frontend && npm run dev
```

**⚠️ 注意**：
- 每次重启本地链，之前的交易历史会清空
- 但合约地址保持不变（所以前端配置不用改）
