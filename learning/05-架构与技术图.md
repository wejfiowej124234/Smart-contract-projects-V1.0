## Part II：验收 Checklist（现场演示打勾，与总览 §10 自检对齐）

- **启动**：`npm run node`（或 `npx hardhat node`）→ `npm run deploy:localhost`（可选 `npm run deploy:p9` 治理）；生成 deployments/31337.json、frontend/src/contracts/deployments.json、frontend/src/abis/。
- **自证**：`npm run smoke:e2e` 输出含 `OK: approve→supply→borrow→repay→withdraw...`；完整验收为 `npm run p10:gate` exit 0 + evidence-pack 四锚点（总览 §6、§7）。
- **钱包**：Connect 后弹 MetaMask；切链 31337；chainId 与 account 显示正确。
- **仪表盘**：余额、pool、position、healthFactor、maxBorrow/maxWithdraw 随交易变化。
- **交易**：预确认弹窗 → Supply（allowance 不够先 approve）→ Borrow/Repay/Withdraw；Tx 行 signing→pending→confirmed。
- **实时更新**：confirmed 后刷新 + 事件监听；不手动刷新也能更新。
- **诊断页**：访问 /diagnostics，Read chainId、Wallet chainId、Deployments 三项 Yes。
- **治理（可选）**：deploy:p9 后访问 /governance，完成一次提案或投票（见 [docs/15-governance-create-proposal-example](../docs/15-governance-create-proposal-example.md)）。

证据索引（面试可点）：[deploy.ts](../scripts/deploy/deploy.ts)、[export.ts](../scripts/_lib/export.ts)、[useWallet.ts](../frontend/src/hooks/useWallet.ts)、[useDashboard.ts](../frontend/src/hooks/useDashboard.ts)、[useActions.ts](../frontend/src/hooks/useActions.ts)、[tx.ts](../frontend/src/state/tx.ts)、[errors.ts](../frontend/src/state/errors.ts)、[SimpleLending.integration.ts](../test/integration/SimpleLending.integration.ts)。岗位证据包见 [09-证据与验收](09-证据与验收-录屏与岗位清单.md)。

## Part IV：风险→控制→证据

- **合约层**：重入 → nonReentrant；ERC20 异常 → SafeERC20；紧急暂停 → Pausable；LTV 约束 → require。证据：LendingPoolImpl.sol。
- **前端层**：精度 → bigint；pending/刷新 → 状态机+持久化；事件丢失 → backfill；误操作 → PreflightModal。证据：amount.ts、tx.ts、txStore.ts、useDashboard.ts、usePreflight.ts。

建议背 3 条：自动切链、approveIfNeeded、event-driven refresh + backfill。
