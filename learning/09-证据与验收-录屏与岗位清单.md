# 证据与验收：录屏模板 + 岗位定制证据包

> 目标：准备“看得见的证据”，按岗位最短时间讲清楚 + 最快拿出证据。  
> 正式验收为 [项目总览架构](项目总览架构.md) §6、§7 的 **p10:gate** exit 0 + evidence-pack 四锚点。

---

## Part I：录屏与截图模板（Plan A / Plan B）

### Plan A：UI 录屏（建议 3-5 分钟）

**A1) 环境证据（约 10 秒）**
- 终端 1：`npm run node`（或 `npx hardhat node`）RPC 在 `http://127.0.0.1:8545`
- 终端 2：`npm run deploy:localhost` 跑完，显示 Exported ABIs + deployments  
可选：打开 `frontend/src/contracts/deployments.json` 展示地址来源。

**A2) 连接与网络（约 20 秒）**
- 页面 Connect 后显示 account + chainId=31337
- 可选：切到别的网络演示 Wrong network 提示，再一键切回 31337

**A3) 最小闭环交易（2-3 分钟）**
1) Supply：输入金额 → Supply → **预确认弹窗**「Confirm & open wallet」→ 若需授权先 Approve 再 Supply  
2) Borrow → 3) Repay → 4) Withdraw（每步预确认 → MetaMask 确认）  
每步成功标志：Tx 行 signing→pending→confirmed；position 的 supplied/borrowed/healthFactor 有变化；无需手动刷新。

### Plan B：smoke:e2e 录屏（30-60 秒兜底）

- 运行 `npm run smoke:e2e`，输出含 `OK: approve→supply→borrow→repay→withdraw flow succeeded...`
- 话术：脚本复用导出 ABI/地址做链上交互，证明部署+合约闭环没问题；UI 临场翻车时可作救场证据。

### 快速证据清单（6 张图）

1) node 终端 RPC running  
2) deploy:localhost 终端 Exported  
3) 页面 Connect（account + chainId=31337）  
4) Supply confirmed（Tx + supplied 变化）  
5) Borrow confirmed（borrowed + healthFactor）  
6) smoke:e2e 输出 OK

## Part II：岗位定制验收与证据包

### 0) 通用：30 秒自证闭环（所有岗位）

- 必跑：`npm run smoke:e2e`
- 话术：“脚本跑完整 approve→supply→borrow→repay→withdraw，OK 即证明 Part 1 + 合约交互闭环没问题。”  
UI 临场翻车时用此救场。

---

### 1) 前端岗

**1.1 必演示步骤（5 分钟内）**  
Connect（点击才弹 MetaMask）→ 切链 31337 → Dashboard（余额/pool/position/maxBorrow/maxWithdraw）→ Supply（预确认→allowance 不够先 approve）→ confirmed 后 UI 自动刷新/事件监听触发刷新。

**1.2 必截图/录屏**  
连接、Dashboard、Supply tx（pending→confirmed）、position 变化、事件刷新（或“不刷新也更新”片段）、smoke:e2e OK。

**1.3 60 秒话术**  
“前端 ethers v6，读写分离：读链用 provider 不弹钱包，写链用 signer 才弹签名。” “交易走 runTxDetailed 状态机：signing/pending/confirmed/failed/stuck，能处理超时和替换。” “刷新三层：confirmed 后强制 refresh + 事件监听 + backfill 兜底。”

**1.4 源码定位（追问可点）**  
useWallet.ts（ensureCorrectNetwork）、useDashboard.ts（scheduleRefresh + lending.on/off）、usePreflight.ts / PreflightModal.tsx、useActions.ts、tx.ts、errors.ts。

---

### 2) 合约岗

**2.1 必演示步骤（5 分钟内）**  
`npm run node` → `npm run deploy:localhost`（可选 deploy:p9）；解释 LTV=75% 与 revert 文案；1 成功 + 1 revert；`npm test`（8 个 integration）。

**2.2 必截图/录屏**  
deploy 输出、node 交易、revert 测试通过、view（getPoolInfo/getUserPosition/calculateMaxBorrow/calculateMaxWithdraw）存在。

**2.3 60 秒话术**  
“单币种简化借贷：supply 作抵押，borrow 受 LTV=75%；healthFactor 表达安全边界。” “view：poolInfo/position/maxBorrow/maxWithdraw。” “OZ：Ownable/Pausable/ReentrancyGuard/SafeERC20，只体现工程安全习惯。”

**2.4 源码定位**  
[contracts/core/LendingPoolImpl.sol](../contracts/core/LendingPoolImpl.sol)、[contracts/tokens/TestToken.sol](../contracts/tokens/TestToken.sol)、[scripts/deploy/deploy.ts](../scripts/deploy/deploy.ts)、[scripts/_lib/export.ts](../scripts/_lib/export.ts)、[test/integration/SimpleLending.integration.ts](../test/integration/SimpleLending.integration.ts)。

---

### 3) 全栈岗

**3.1 必演示步骤（8–10 分钟）**  
三终端 node / deploy / frontend；UI 完整 approve→supply→borrow→repay→withdraw；演示“重启 node 导致地址失效”并用 deploy 修复；`npm run smoke:e2e`。

**3.2 必截图/录屏**  
三终端、Connect、Supply/Borrow、healthFactor 变化、smoke:e2e OK。

**3.3 60 秒话术**  
“工程线：contracts→deploy→export ABI/地址；运行线：useWallet→useDashboard→useActions。” “两套验收：UI 现场演示 + smoke:e2e 一键闭环自证。”

---

### 4) 提交/面试前 3 条检查（通用）

1) 重启过 node 必须重新 deploy:localhost  
2) UI 出问题先跑 smoke:e2e  
3) 失败/卡住先看 tx 状态机（stuck/替换）、再看 normalizeError
