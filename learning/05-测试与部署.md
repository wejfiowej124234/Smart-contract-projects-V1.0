## 1. 测试基础

### 1.1 为什么要测试智能合约？

```
智能合约特点：
- 部署后无法修改
- 错误可能导致资金损失
- 运行在公开的区块链上

因此测试非常重要！
```

### 1.2 测试类型

```
单元测试：测试单个函数
集成测试：测试完整流程
E2E 测试：模拟真实用户操作
```

## 2. Hardhat 测试

### 2.1 基本结构

```typescript
import { expect } from "chai";
import { ethers } from "hardhat";

describe("SimpleLending", () => {
  it("should supply tokens", async () => {
    // 1. 准备
    const [user] = await ethers.getSigners();
    const token = await deployToken();
    const lending = await deployLending(token.address);
    
    // 2. 执行
    await token.approve(lending.address, amount);
    await lending.supply(amount);
    
    // 3. 验证
    const position = await lending.getUserPosition(user.address);
    expect(position.supplied).to.eq(amount);
  });
});
```

### 2.2 运行测试

```bash

npm test

# 只运行特定文件
npx hardhat test test/SimpleLending.integration.ts

# 显示 gas 使用
REPORT_GAS=true npm test
```

## 3. 部署流程

### 3.1 部署脚本结构

```typescript
// scripts/deploy.ts
async function main() {
  // 1. 获取部署账号
  const [deployer] = await ethers.getSigners();
  console.log("Deploying with:", deployer.address);
  
  // 2. 部署 USD8 代币
  const USD8 = await ethers.getContractFactory("TestToken");
  const usd8 = await USD8.deploy("USD8", "USD8");
  await usd8.waitForDeployment();
  console.log("USD8 deployed to:", await usd8.getAddress());
  
  // 3. 部署借贷合约
  const Lending = await ethers.getContractFactory("SimpleLending");
  const lending = await Lending.deploy(await usd8.getAddress());
  await lending.waitForDeployment();
  console.log("Lending deployed to:", await lending.getAddress());
  
  // 4. Seed 测试账号
  await usd8.transfer(seedAddress, parseUnits("10000", 18));
  
  // 5. 导出配置
  exportABIs();
  exportDeployments();
}

main().catch(console.error);
```

### 3.2 部署到不同网络

```bash
# 本地链（默认）
npx hardhat run scripts/deploy.ts --network localhost

# Sepolia 测试网（需要配置）
npx hardhat run scripts/deploy.ts --network sepolia

# 主网（谨慎！）
npx hardhat run scripts/deploy.ts --network mainnet
```

## 4. Hardhat 配置

### 4.1 hardhat.config.ts 关键配置

```typescript
export default {
  solidity: {
    version: "0.8.19",
    settings: {
      optimizer: {
        enabled: true,
        runs: 200,  // 优化运行次数
      },
    },
  },
  
  networks: {
    localhost: {
      url: "http://127.0.0.1:8545",
      chainId: 31337,
    },
    sepolia: {
      url: process.env.SEPOLIA_RPC_URL,
      accounts: [process.env.PRIVATE_KEY],  // 从环境变量读取
    },
  },
};
```

## 10. 常见问题

### Q: 测试失败怎么办？

```
1. 检查错误信息
2. 确认本地链是否运行
3. 清理缓存：npx hardhat clean
4. 重新编译：npx hardhat compile
```

### Q: 部署后前端找不到合约？

```
1. 检查 deployments/31337.json 是否生成
2. 检查 frontend/src/abis/ 是否有 ABI 文件
3. 重启前端：cd frontend && npm run dev
```

### Q: Gas 费用太高怎么办？

```
1. 本地链不需要真实 gas
2. 测试网可以调整 gasPrice
3. 优化合约代码减少 gas 使用
```
