## 第一步：安装基础软件

### 1.1 安装 Node.js

**检查是否已安装**：
```bash
node --version
# 如果显示 v18.x.x 或更高，跳过此步骤
```

**安装步骤**（如果未安装）：
1. 访问 https://nodejs.org/
2. 下载 LTS 版本（长期支持版）
3. 双击安装包，一路下一步
4. 重启命令行，运行 `node --version` 验证

### 1.2 安装 Git

**检查是否已安装**：
```bash
git --version
# 如果显示 git version x.x.x，跳过此步骤
```

**安装步骤**（如果未安装）：
1. 访问 https://git-scm.com/
2. 下载对应操作系统的版本
3. 安装时全部默认选项即可

### 1.3 安装 VS Code

1. 访问 https://code.visualstudio.com/
2. 下载安装
3. 推荐安装插件：
   - Solidity（作者：Juan Blanco）
   - ESLint

1. 在 Chrome 浏览器中访问：
   https://metamask.io/download/

3. 添加到 Chrome
4. 如果是第一次使用：

**⚠️ 重要提示**：
- 助记词是恢复钱包的唯一方式，务必保管好


```bash
# Mac/Linux:
lsof -i :8545
kill -9 <PID>
```

## 第八步：完整操作流程

### 8.1 连接钱包

1. 点击页面上的"Connect Wallet"按钮
2. MetaMask 会弹出，选择账号
3. 点击"下一步" → "连接"
4. 页面应该显示：
   - 你的地址（前 6 位和后 4 位）
   - 链 ID：31337
   - 余额信息

**如果出现"Wrong Network"**：
- 点击页面上的"Switch to Hardhat Local"
- MetaMask 会提示切换网络
- 批准即可

### 8.2 存款（Supply）

1. 在「Supply (USD8)」输入金额，例如：`500`
2. 点击「Supply」或「Approve USD8」（若额度不足会先显示 Approve）
3. 会先弹出**预确认弹窗**（Confirm transaction (pre-wallet)），核对金额与链 ID 后点「Confirm & open wallet」
4. MetaMask 弹出：若需授权则先确认「支出上限」Approve，再确认 Supply 交易
5. 观察页面：状态 Signing → Pending → Confirmed；仪表盘自动更新；User Position 里 Supplied 增加

### 8.3 借款（Borrow）

1. 检查「Max borrowable (safe)」：例如抵押 500 时约为 375（500×75%）
2. 在「Borrow」栏输入金额（可点 Max 填满安全额度），例如：`375`
3. 点击「Borrow」→ 预确认弹窗 → 「Confirm & open wallet」→ MetaMask 确认（Borrow 无需 Approve）
4. 观察：User Position 里 Borrowed 增加；Health Factor 显示为比例（如 1.00 表示 100%，借满时约 1.0 At risk）；钱包 USD8 余额增加借出额

### 8.4 还款（Repay）

1. 在「Repay」栏输入要还金额（可点 Max 还清），例如：`375`
2. 点击「Repay」→ 预确认弹窗 → 确认
3. 若额度不足会先弹出 MetaMask「支出上限」Approve，确认后再确认 Repay 交易
4. 观察：Borrowed 减少；Health Factor 上升；无债务时显示「No debt」

### 8.5 取款（Withdraw）

1. **先还清或部分还款**，使健康因子允许提现（无债务时 Max withdraw = 全部抵押）
2. 在「Withdraw」栏输入金额（可点 Max）
3. 点击「Withdraw」→ 预确认弹窗 → MetaMask 确认（Withdraw 不需 Approve）
4. 观察：Supplied 减少、钱包 USD8 增加

**⚠️ 注意**：有未还借款时，提现会降低抵押、健康因子会掉，合约会拒绝「不健康」的提现；要先 Repay 再 Withdraw。

### 8.6 诊断页与治理（可选，与总览 §10 自检对齐）

- **诊断页**：访问 **/diagnostics**，确认「Read chainId」「Wallet chainId」「Deployments」三项均为 **Yes**（即 GATE 通过）；可点击「Copy debug bundle」便于排错。
- **治理**：若已执行 `npm run deploy:p9`，可访问 **/governance**，完成一次创建提案或投票；步骤见 [docs/15-governance-create-proposal-example.md](../docs/15-governance-create-proposal-example.md)。总览 §10 自检要求：本地跑通 node → deploy:localhost → deploy:p9 → 前端 → 31337 → /diagnostics 三项 Yes → 一次 Supply + 一次治理提案/投票。

## 常见问题排查

### ❌ 问题 1：MetaMask 显示"Internal JSON-RPC error"

**原因**：
- 本地链重启了，但 MetaMask 还记得旧的交易 nonce

**解决**：
1. MetaMask → 设置 → 高级 → 重置账户
2. 确认重置
3. 刷新页面

### ❌ 问题 2：合约调用失败"nonce too low"

**原因**：同上

**解决**：重置 MetaMask 账户

### ❌ 问题 3：页面一直显示"Loading..."

**检查**：
1. 本地链是否在运行？
   ```bash
   curl http://localhost:8545
   # 应该返回一些 JSON
   ```
2. 合约是否部署？
   ```bash
   cat deployments/31337.json
   # 应该有内容
   ```
3. 浏览器控制台有无错误？
   - F12 打开开发者工具
   - 切换到 Console 标签
   - 看是否有红色错误

### ❌ 问题 4：交易一直 Pending

**可能原因**：
1. MetaMask 没连接到正确的网络
   - 检查 MetaMask 顶部是否显示"Hardhat Local"
2. 本地链停止了
   - 检查第一个终端是否还在运行

### ❌ 问题 5："Insufficient gas"

**原因**：
- 账户 ETH 不足（虽然有 10000 但可能被其他交易消耗了）

**解决**：
- 重启本地链（会重置余额）
- 或者导入另一个 Hardhat 默认账号

每次使用只需要这三步：

```bash

# Terminal 2: 部署合约

# Terminal 3: 启动前端
```

- 若未重新部署，前端使用的合约地址已失效，会出现 "contract has no code" 等错误

## 进阶：一条命令验收（p10:gate + evidence-pack）

本项目**唯一正式验收**为：端口 8545 空闲下执行 **`npm run p10:gate`** 至 **exit 0**（会起链 → 部署 → 治理 → 生成 evidence-pack，输出含 EVIDENCE-PACK-MANIFEST-SHA256 及四锚点）。  
学完本动手实验后，可尝试在**新开终端、关闭其他占用 8545 的进程**后运行：

```bash
npm run p10:gate
```

成功时控制台会打印 `EVIDENCE-PACK-MANIFEST-SHA256`，且 `evidence-pack/` 目录下会生成 manifest、evidence-summary 等文件。详见根目录 [RELEASE_CHECKLIST_P10.md](../RELEASE_CHECKLIST_P10.md)、[docs/03-08-deployment-runbook.md](../docs/03-08-deployment-runbook.md) §8。
