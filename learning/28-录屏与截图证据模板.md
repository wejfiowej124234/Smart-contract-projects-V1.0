# 录屏与截图证据模板（投简历/线上面试都能用）

> 目标：准备一套“看得见的证据”，面试官不用相信你说的，只要看证据就能确认你跑通了闭环。
>
> 建议：先按 **Plan A（UI）** 录一遍；再按 **Plan B（smoke:e2e）** 录一遍当兜底。

---

## Plan A：UI 录屏（建议 3-5 分钟）

### A1) 环境证据（10 秒）

- 截图：终端 1 `npm run node` 正在跑
  - 成功标志：显示 RPC 在 `http://127.0.0.1:8545`
- 截图：终端 2 `npm run deploy:localhost` 跑完的输出
  - 成功标志：显示 Exported ABIs + deployments

可选加分：打开 `frontend/src/contracts/deployments.json` 给一眼看地址来源。

### A2) 连接与网络（20 秒）

- 截图：页面点击 Connect 后显示 account + chainId=31337
- 截图：Wrong network 提示（可选演示：切到别的网络，显示 banner + 按钮禁用，再一键切回 31337）

### A3) 最小闭环交易（2-3 分钟）

按顺序操作并录屏：
1) Supply（必要时先 Approve）
2) Borrow
3) Repay（必要时先 Approve）
4) Withdraw

每一步的成功标志（至少截 1 张）：
- Tx 行出现 `signing → pending → confirmed`
- position 的 supplied/borrowed/healthFactor 有变化
- 不需要手动刷新页面也能更新（confirmed refresh 或事件刷新）

---

## Plan B：smoke:e2e 录屏（30-60 秒，强力兜底证据）

- 录屏：运行 `npm run smoke:e2e`
- 成功标志：输出包含 `OK: approve→supply→borrow→repay→withdraw flow succeeded...`

说明话术（面试可用）：
> 这个脚本复用导出的 ABI/地址直接做链上交互，所以它能证明“部署导出链路 + 合约交互闭环”没问题，帮助把问题定位到 UI/钱包层还是链路层。

---

## 快速证据清单（只准备 6 张图也够用）

1) `npm run node` 终端：RPC running
2) `npm run deploy:localhost` 终端：Exported ABIs + deployments
3) 页面：Connect 成功（account + chainId=31337）
4) 页面：Supply confirmed（Tx 行 + supplied 变化）
5) 页面：Borrow confirmed（borrowed 变化 + healthFactor 变化）
6) 终端：`npm run smoke:e2e` 输出 OK（兜底闭环证据）
