# 部署、测试与前端读写（流水线 + 读写/状态机）

## Part I：部署与导出

- **链下配置**：deploy 依赖 `configs/profiles/<mode>/profile.json`、`scripts/config/loadProfile.ts`、`scripts/config/reserves.31337.json`；配置缺失见 [09-本地链标准与地址](../docs/09-本地链标准与地址.md)、总览 §11。
- **scripts/deploy/deploy.ts**：读 chainId（loadProfile）→ 部署 USD8/WETH、proxy+池子+oracle+configurator+treasury 等 → seedTo 前 5 账户（+ 可选 SEED_ADDRESS）→ exportArtifacts。
- **deploy:p9**：`npm run deploy:p9` 部署治理（GovernorP9、Timelock、GovernanceToken），配置角色；导出含 GovToken、GovernorP9 的 abis 与 deployments；治理页有数据需先跑 deploy:p9。
- **exportArtifacts**（scripts/_lib/export.ts）：写 deployments/<chainId>.json、frontend/src/contracts/deployments.json、frontend/src/abis/*.json。
- **前端**：getContracts(provider, chainId) 仅返回 usd8/weth/lending；治理用 getDeployments + GovernorP9/GovToken。

## Part III：前端读写与状态机

- **读**：useDashboard + contracts.ts；Promise.all 读余额/pool/position/max；钱包断开清空 data。**写**：useActions + write.ts + tx.ts；approveIfNeeded → supply/withdraw/borrow/repay；状态机 idle→signing→pending→confirmed/failed/stuck；pending 持久化；post-state 验证。
- **事件**：lending.on(Supplied/Withdrawn/Borrowed/Repaid)，节流 250ms + backfillEvents 兜底。
- **useWallet**：ensureCorrectNetwork(31337)、accountsChanged/chainChanged、localStorage。**useActions**：runTxDetailed、超时→stuck、TRANSACTION_REPLACED、loadPendingTx。
