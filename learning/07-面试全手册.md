## Part I：高频问题与回答要点

- **Q1 介绍项目**：DeFi 借贷协议，Solidity+OZ+Hardhat，React+TS+ethers v6；存/借/还/取，LTV 75%；事件驱动 UI+节流+backfill；预确认、approveIfNeeded、交易状态机与 post-state 验证。避免只说“简单借贷”、只背 README。
- **Q2–Q4 智能合约/OZ/防重入**：链上自动执行、不可变（除代理）、透明、gas、确定性。OZ：Ownable、Pausable、ReentrancyGuard、SafeERC20。防重入：nonReentrant + CEI（先状态后外部调用）。
- **Q5 approve**：transferFrom 需 allowance；前端 approveIfNeeded，不足先 approve 再 supply/repay。
- **Q6 UI 更新/pending**：事件为主+节流+backfill；状态机+pending 持久化，刷新后 loadPendingTx，超时标 stuck。
- **Q7 治理/deploy:p9/诊断页**：治理页有数据需先跑 `npm run deploy:p9`；getDeployments 提供 governorAddress、governanceTokenAddress，Governance 页用 GovernorP9/GovToken ABI 读提案、投票、发 propose/castVote。诊断页 /diagnostics 可查 Read chainId、Wallet chainId、Deployments 三项是否 Yes。治理示例见总览 §9 延伸阅读、[docs/15-governance-create-proposal-example](../docs/15-governance-create-proposal-example.md)；排错见总览 §11。

证据点统一：LendingPoolImpl.sol、useDashboard.ts、useActions.ts、tx.ts、deploy.ts、SimpleLending.integration.ts；治理见 useGovernanceOverview、getDeployments。

## Part II：准备与表达

- **3 天法**：第 1 天通读文档+跑 3 次；第 2 天 5 分钟演示+3 难点+5 反问；第 3 天模拟+设备检查。
- **STAR**：Situation→Task→Action→Result。技术答法：直接回答→举例→扩展→反问。不会时说“我目前理解是…会这样去做，有误请指正”+反问。
- **5 分钟演示**：Connect → Supply（预确认→必要时 Approve）→ Borrow → Repay → Withdraw；讲读写分离、事件刷新、状态机。详见 [04-动手实验](04-动手实验.md) 或下文 Part III。

## Part III：亮点与 30秒/2分钟/5 分钟话术

- **30 秒**：可复现 DeFi 借贷 Demo，Hardhat 31337，Solidity+OZ + React+TS+ethers v6；完整存/借/还/取，事件刷新+状态机与兜底。
- **2 分钟**：项目定位→技术栈（合约/前端/测试/部署）→核心功能（钱包/仪表盘/四动作/预确认/状态机）→亮点（事件+节流+backfill、状态机+持久化、bigint+预确认）→个人收获。
- **5 分钟演示时间轴**：0:00 开场 → 0:10 连接 → 0:40 Supply → 1:40 Borrow → 2:30 Repay → 3:15 Withdraw → 4:00 两条亮点（事件驱动+兜底、状态机+持久化）。救场：`npm run smoke:e2e`。

## Part IV：追问与讲稿（结论→证据）

- **UI 更新**：事件主路径+backfill+节流。证据：useDashboard.ts。
- **读写分离**：读稳定可并发；写有拒绝/换链，分离后确认再刷新。证据：useActions.ts、useDashboard.ts、write.ts。
- **approve**：transferFrom 需 allowance；前端先检查再 approve。证据：useActions.ts。
- **pending/刷新**：状态机+localStorage 持久化，刷新后恢复 wait。证据：tx.ts、txStore.ts、useActions.ts。
- **post-state**：RPC 最终一致性，短时验证；读不到标 unverified。证据：useActions.ts。
- **合约安全**：nonReentrant、SafeERC20、Pausable、Ownable。证据：LendingPoolImpl.sol。
- **LTV/withdraw**：75%；borrow/withdraw 的 require。证据：LendingPoolImpl.sol、useDashboard.ts。
- **测试**：8 个集成，happy path + revert。证据：SimpleLending.integration.ts。
- **治理/deploy:p9**：deploy:p9 部署 GovernorP9、Timelock、GovToken 并导出；治理页用 getDeployments + ABIS.GovernorP9/GovToken 读/写。证据：scripts/deploy/deploy-p9.ts、useGovernanceOverview、frontend abis GovToken/GovernorP9。

**交易状态机讲稿**：idle→signing→pending→confirmed/failed/stuck；stuck 为超时不误判失败；TRANSACTION_REPLACED 跟踪新 hash；pending 持久化与 loadPendingTx。一句话：“把交易当状态机设计，事件为主刷新、backfill/节流兜底。”
