## 五、不建议做的（避免过度或越界）

- **不再增加新 token 种类**：当前 token 已覆盖 P6；新增会提高维护成本，收益有限。
- **不做图表/历史曲线**：题目与 P6 范围均为单页、单池、当前状态；不做 utilization 历史、APY 趋势等。
- **不引入新动效库**：现有 CSS keyframes + prefers-reduced-motion 已满足；不引入 Framer Motion 等以保持依赖与包体可控。
- **不改变布局结构**：两列 Dashboard、2×2 操作区、DataStatusBar 单行等已符合 Aave 对标与 P3；不再改版式。
