# 技术说明与运行指南

面向**评审与面试**的一页技术说明：技术栈、仓库结构、如何运行与验证、文档从哪里看。

---

## 1. 项目定位

- **Smart Contract Coding Test** 完整实现：本地 Hardhat 链 + 前端集成。
- 功能：单资产（USD8）借贷仪表盘，支持 **Approve → Supply、Withdraw、Borrow、Repay**，连接 MetaMask，自动切链/持久化连接，刷新策略为「交易确认 + 合约事件」。
- 范围：单页、单池、本地链演示；不含主网部署、预言机、清算逻辑。

## 4. 如何运行（三步）

1. **启动本地链**（终端 1）：`npx hardhat node`  
2. **部署并导出**（终端 2）：`npx hardhat run scripts/deploy.ts --network localhost`  
3. **启动前端**（终端 3）：`cd frontend && npm ci && npm run dev`  

浏览器访问前端，在 MetaMask 中添加网络 RPC `http://127.0.0.1:8545`、chainId `31337`，连接后即可操作。  
详细步骤与「本地重启后 MetaMask 余额不对」的处理见根目录 **LOCAL_RUN_步骤.md**。

---

## 5. 如何验证（自检 / CI）

- **合约**：`npm run compile`，`npm test`  
- **前端**：`cd frontend && npm run lint && npm run build`  
- **一键**：`npm run ci:local`（编译 + 测试 + 前端 lint/build）  
- **E2E 流程**：`npm run smoke:e2e`（可选，需先启动节点并部署）
