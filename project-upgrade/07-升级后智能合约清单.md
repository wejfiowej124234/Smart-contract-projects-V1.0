# 升级后智能合约清单（数量与功能）

> 升级完成后，链上智能合约的数量、所属模块及主要功能（函数级摘要）。

---

## 1) 数量汇总

| 模块 | 合约/库数量 | 说明 |
|------|-------------|------|
| core | 9 | Pool, PoolConfigurator, ReserveLogic, UserConfiguration, InterestRateStrategy, RiskEngine, Liquidation, FlashLoan, Treasury |
| tokens | 3+ | aToken 实现、debtToken（variable/stable）、可选 incentives |
| oracle | 5 | OracleRouter, ChainlinkAdapter, DexTwapAdapter, PriceBoundGuard, SequencerUptimeGuard |
| governance | 4 | Governor, Timelock, AccessControl, EmergencyModule |
| upgrade | 2–3 | ProxyAdmin, TransparentProxy 或 UUPSProxy（选型其一） |
| crosschain | 0–2 | 可选 BridgeAdapter, MessageReceiver |
| libs | 4 | WadRayMath, SafeTransfer, Errors, Events |
| interfaces | 若干 | IPool, IOracle, IInterestRateStrategy 等（不计入「部署合约」数量） |

**合计（仅部署/实现合约）**：约 **27–32 个**（含可选跨链与不同代理选型）。若 aToken/debtToken 按资产各 1 个实现，则随资产数增加而增加。

**是否经代理**：下表「是否经代理」列标明该合约是否通过 TransparentProxy/UUPS 对外；用户/前端只记代理地址，升级时只换实现。库（ReserveLogic 等）不单独部署，填「—」。

**前端实际使用的部署键**（以 frontend/src/contracts/deployments.json 为准）：usd8Address、wethAddress、simpleLendingAddress、aTokenAddress、variableDebtTokenAddress、oracleRouterAddress、configuratorAddress、governanceTokenAddress、timelockAddress、governorAddress、emergencyModuleAddress、proxyAdminAddress、mockAggregatorAddress；每条记录含 **chainId**，多链时以 chainId 为 key。**完整键名顺序与数据流**见 **docs/09-本地链标准与地址** Part 2、Part 3；与下表合约一一对应。

**与当前实现命名/路径对照**（本仓已实现，命名与本文略有差异）：  
| 本文/07 名称 | 本仓实现 |
|-------------|----------|
| Pool | **LendingPoolImpl.sol**（经代理对外，前端用 simpleLendingAddress） |
| InterestRateStrategy | **LinearRateStrategy.sol**（实现 IInterestRateStrategy） |
| Governor | **GovernorP9.sol** |
| Timelock | OpenZeppelin **TimelockController**（非独立合约名） |
| ProxyAdmin / TransparentProxy | OZ 实现，经 **ImportProxy.sol** 引用；deploy 脚本部署 ProxyAdmin |
| 测试目录 | 本仓为 **test/**（非 tests/），见《06-升级后目录结构》§3 |

详见《00-与当前代码对齐说明》§3 命名与结构差异汇总。

## 2) 按模块的合约与主要功能

### 2.1 core

| 合约/库 | 类型 | 是否经代理 | 主要功能 |
|---------|------|------------|----------|
| **Pool** | 合约 | **是** | supply, withdraw, borrow, repay；getReserveData, getUserAccountData；setUserUseReserveAsCollateral（多资产）；入口调 ReserveLogic/RiskEngine/InterestRate |
| **PoolConfigurator** | 合约 | **是** | initReserves, setLTV, setLiquidationThreshold, setLiquidationBonus, setInterestRateStrategy, setReservePause；仅 Timelock/Admin |
| **ReserveLogic** | 库 | — | 单池记账：updateInterestRates, updateState, cumulateToLiquidityIndex/cumulateToBorrowIndex；getNormalizedIncome/NormalizedDebt；mintToTreasury |
| **UserConfiguration** | 库 | — | 用户抵押位图：isUsingAsCollateral, setUsingAsCollateral, getIsolationState（若支持隔离） |
| **InterestRateStrategy** | 合约/接口 | 否 | getSupplyRate, getBorrowRate（基于 utilization）；可多实现（线性/kink/多段） |
| **RiskEngine** | 库 | — | calculateHealthFactor, validateBorrow, validateWithdraw；getMaxBorrow, getMaxWithdraw；isLiquidatable |
| **Liquidation** | 合约/库 | **是**（若为合约） | liquidationCall（清算入口）；部分清算、closeFactor、bonus；与 Pool/Reserve/Treasury 交互 |
| **FlashLoan** | 合约/库 | 可选 | executeFlashLoan；费率、白名单、单次上限 |
| **Treasury** | 合约 | 否 | 接收协议收入、储备金注入、坏账覆盖；withdraw, setReserveFactor |

### 2.2 tokens

| 合约 | 类型 | 是否经代理 | 主要功能 |
|------|------|------------|----------|
| **aToken** | 合约 | 否 | mint, burn（仅 Pool 调）；transfer, balanceOf；累积利息（基于 liquidityIndex）；approve, allowance |
| **variableDebtToken** | 合约 | 否 | mint, burn（仅 Pool 调）；balanceOf；累积利息（基于 borrowIndex） |
| **stableDebtToken** | 合约 | 否 | 可选；固定利率债务、repay 重算期限 |
| **incentives** | 合约 | 否 | 可选；奖励分配、claim（与 staking/激励池对接） |

### 2.3 oracle

| 合约 | 类型 | 是否经代理 | 主要功能 |
|------|------|------------|----------|
| **OracleRouter** | 合约 | 可选 | getPrice(asset), getPrices(assets)；内部路由 Chainlink/TWAP/Fallback；返回统一 decimals |
| **ChainlinkAdapter** | 合约/库 | 否 | 读 Chainlink 聚合器；校验 heartbeat、minAnswer/maxAnswer |
| **DexTwapAdapter** | 合约 | 否 | 可选；Uniswap V3 TWAP 等 DEX 价格 |
| **PriceBoundGuard** | 合约/库 | 否 | 偏离阈值、熔断、最大价差；异常时 revert 或降级 |
| **SequencerUptimeGuard** | 合约 | 否 | L2 用；sequencer down 时拒绝或延迟价格使用 |

### 2.4 governance

| 合约 | 类型 | 是否经代理 | 主要功能 |
|------|------|------------|----------|
| **Governor** | 合约 | 否 | propose, castVote, queue, execute；与 Timelock 配合 |
| **Timelock** | 合约 | 否 | executeTransaction, delay；PoolConfigurator 等仅 Timelock 可调 |
| **AccessControl** | 合约/库 | 否 | 角色：DEFAULT_ADMIN, PAUSER, GUARDIAN, CONFIGURATOR；grantRole, revokeRole |
| **EmergencyModule** | 合约 | 否 | emergencyPause, setAssetFrozen, setLTVEmergency；仅 Guardian |

### 2.5 upgrade

| 合约 | 类型 | 是否经代理 | 主要功能 |
|------|------|------------|----------|
| **ProxyAdmin** | 合约 | 否（管理端） | upgrade, upgradeAndCall；管理代理实现地址 |
| **TransparentProxy** | 合约 | 是（代理本体） | 透明代理；delegatecall 到实现；Admin 与实现分离 |
| **UUPSProxy** | 合约 | 是（代理本体） | 可选；升级逻辑在实现合约内（upgradeToAndCall） |

### 2.6 libs（不单独部署，被内联或 delegatecall）

| 库 | 是否经代理 | 主要功能 |
|----|------------|----------|
| **WadRayMath** | — | 1e18/1e27 定点乘除、wadMul/rayMul、避免溢出 |
| **SafeTransfer** | — | safeTransferFrom/safeTransfer 封装、返回值检查 |
| **Errors** | — | 统一错误码/ revert 文案 |
| **Events** | — | 统一事件定义 |

### 2.7 crosschain（可选）

| 合约 | 是否经代理 | 主要功能 |
|------|------------|----------|
| **BridgeAdapter** | 可选 | 跨链消息发送/接收、流动性桥接 |
| **MessageReceiver** | 可选 | 接收跨链消息、执行本地操作（如流动性注入） |
