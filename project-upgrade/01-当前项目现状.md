## 1) 项目定位

- **类型**：单币种借贷 Demo（MVP），用于演示与验收，非生产就绪。
- **链**：Hardhat 本地链（chainId 31337），单链。
- **资产**：USD8 同时作为抵押与借出资产；WETH 仅前端展示，不参与协议。
- **存量**：当前为本地链 Demo，无主网存量；若未来从主网旧合约迁移，需单独制定数据迁移与双跑方案；本包占位见《archive/misc/迁移方案-占位》。

## 2) 环境与网络清单（升级前后）

**用途**：明确 local / testnet / mainnet 的划分、chainId、RPC、部署顺序与切换条件；实现时按环境选 config 与 runbook。

| 环境 | chainId | RPC / 节点 | 用途 | 部署顺序与切换 |
|------|---------|------------|------|----------------|
| **local** | 31337 | Hardhat 本地（如 http://127.0.0.1:8545） | 开发、集成测试、Mock 场景 | 最先使用；脚本/前端默认连本地；切换即改 .env 或 hardhat.config 的 defaultNetwork |
| **testnet** | 视链而定（如 11155111 Sepolia） | 公共或自建 RPC | 预发布、社区测试、审计验证 | local 通过后再部署 testnet；config 用 reserves.\<chainId\>.json（如 reserves.11155111.json）；key 与 mainnet 隔离 |
| **mainnet** | 视链而定（如 1 Ethereum） | 公共或自建 RPC | 生产 | testnet 稳定、审计与治理就绪后再部署；详见目标仓库 **docs/03-08-deployment-runbook.md** |

- **当前**：仅使用 **local**（chainId 31337）；无 testnet/mainnet。
- **升级后**：建议仍先 local 全流程跑通，再按需开通 testnet/mainnet；目标仓库 **docs/03-08-deployment-runbook.md** 中应写明各环境的 key 管理、config 路径、部署顺序与回滚条件。

**推荐环境与工具链版本**（实现时建议统一，避免兼容问题）：

| 项目 | 建议版本 | 说明 |
|------|----------|------|
| Node | 18+（LTS） | 当前仓库与 Hardhat/ethers 已在用；升级后脚本与前端建议一致 |
| Hardhat | 2.x | 与当前项目一致；升级后若用 Foundry 可并存 |
| Solidity | 0.8.x | 与当前合约一致；升级后核心合约建议 0.8.19+ 并锁定 |
| 包管理 | npm 或 pnpm | 本包以 npm 为例；目标仓库可自定 |

详细版本以目标仓库 **README** 或 **docs/03-08-deployment-runbook.md** 为准；本包不写死具体小版本。

## 5) 当前架构（单合约单资产）

- **用户** → 前端（React）→ ethers v6 → **SimpleLending**（单合约完成 supply/withdraw/borrow/repay）。
- **价格**：无预言机，抵押与债务同币种 1:1 计价。
- **利率**：合约内简单公式（utilization → supplyRate/borrowRate），无独立利率策略合约。
- **风控**：仅 LTV 硬约束（75%），无清算逻辑、无 Guardian、无 Timelock。
- **部署**：单脚本部署 USD8/WETH/SimpleLending，导出地址与 ABI 到 frontend。

## 6) 与行业顶级 DeFi 借贷的差距（简要）

| 维度 | 当前 | 行业顶级 |
|------|------|----------|
| 资产 | 单资产 | 多资产、aToken/debtToken、隔离/共享配置 |
| 价格 | 无 | Oracle 路由（Chainlink/TWAP/熔断/心跳） |
| 利率 | 内嵌简单公式 | 可插拔利率策略、kink 曲线、多段 |
| 清算 | 无 | 清算模块（closeFactor/部分清算/奖励/坏账/拍卖） |
| 治理 | 仅 Owner | Governor + Timelock + Guardian + 参数配置器 |
| 升级 | 无 | 代理模式（Transparent/UUPS）+ 升级流程 |
| 安全 | ReentrancyGuard/Pausable | + 形式化验证、不变量测试、Fuzz、审计证据包 |
| 链下 | 无 | 清算机器人、Keeper、Subgraph、监控告警 |
