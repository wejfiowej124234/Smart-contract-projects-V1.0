## 2) 攻击面与防护措施（清单）

### 2.1 预言机 / 价格攻击

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 单源造假或失效 | 多源（Chainlink + TWAP/备用）；主源不可用时降级或 revert | [ ] |
| 闪贷/闪电贷操纵价格 | 使用 TWAP 或至少同区块内不依赖单笔交易价格；PriceBoundGuard 限制短时波动 | [ ] |
| 心跳过期仍被使用 | Oracle 层校验 heartbeat；超时则 revert 或降级 | [ ] |
| L2 Sequencer 宕机用错价格 | SequencerUptimeGuard；sequencer down 期间不采用新区块价格 | [ ] |

### 2.2 重入与回调

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 重入到 Pool / Liquidation | 所有写路径 nonReentrant；外部调用后不依赖可重入的状态变更 | [ ] |
| ERC20 非标准返回值 | SafeERC20；不信任 transfer 返回值未检查的合约 | [ ] |
| 回调中再次调用协议 | 关键路径不信任用户可控回调；或严格 reentrancy guard | [ ] |

### 2.3 权限与访问控制

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 配置被任意地址修改 | PoolConfigurator 仅 Timelock（或指定 Admin）可调；AccessControl 校验 | [ ] |
| 升级权滥用 | ProxyAdmin 所有者为多签或 Timelock；升级走治理流程（见《12-升级流程》） | [ ] |
| 紧急权滥用 | Guardian 仅 Pause/紧急参数；操作可追溯；事后审查文档化 | [ ] |
| 角色混淆 | DEFAULT_ADMIN / PAUSER / GUARDIAN / CONFIGURATOR 分离；最小权限 | [ ] |

### 2.4 清算与 MEV

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 清算激励不足导致坏账堆积 | 设置合理 liquidation bonus；监控坏账与 HF 分布 | [ ] |
| 清算被 MEV 抢跑 | 可选：私有 mempool、拍卖、或接受公开竞争；文档化策略 | [ ] |
| 清算逻辑错误导致资产不守恒 | 不变量测试：清算前后总供应/总借款/储备关系；单元测试覆盖边界 | [ ] |

### 2.5 利率与精度

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 利率或 index 计算溢出/精度损失 | WadRayMath 或等价定点库；测试边界与极端 utilization | [ ] |
| 利率策略被恶意替换 | 利率策略地址仅 PoolConfigurator 可设；治理或 Admin 控制 | [ ] |

### 2.6 升级与存储

| 风险 | 防护措施 | 打勾 |
|------|----------|------|
| 代理存储布局冲突 | 新实现只追加存储；不插槽、不重排；升级前审查 | [ ] |
| 初始化多次执行 | 初始化函数仅执行一次（initializer 或 onlyOnce）；防止重复 init | [ ] |
| 升级后逻辑错误 | 升级前完整测试 + 不变量 + 回归；升级后观察期与回滚预案（见《12-升级流程》） | [ ] |

## 4) 应急与监控

| 关键事件 / 指标 | 告警规则（示例） | 打勾 |
|-----------------|------------------|------|

| **大额 Borrow / Withdraw** | 单笔或单用户超阈值（可配置） | [ ] |

## 8) 具体避免措施与设置要点（速查）

**说明**：以下为「怎么避免」与「一些设置」的要点；实现时在目标仓库代码与 config 中落位，本包仅列项与引用。

| 风险/场景 | 具体避免措施 / 设置 | 见文档 |
|------------|---------------------|--------|
| **预言机单源造假/失效** | 多源（Chainlink + TWAP/备用）；Oracle 层校验 heartbeat、minAnswer/maxAnswer；主源不可用时 revert 或降级 | 09 §2.1；07 oracle；15 §2.A（stalePeriod、asset→feed） |
| **闪贷操纵价格** | 使用 TWAP 或同区块内不依赖单笔交易价格；PriceBoundGuard 限制短时波动；部署时设偏离阈值 | 09 §2.1；07 PriceBoundGuard；15 §2.A |
| **心跳过期仍被使用** | Oracle 读聚合器时校验 lastUpdate + heartbeat；超时 revert 或降级；heartbeat 按链与资产在 config 中设置 | 09 §2.1；07 ChainlinkAdapter；15 §2.A |
| **重入** | 所有写路径 nonReentrant（modifier）；外部调用后不依赖可重入的状态变更；ERC20 用 SafeERC20 | 09 §2.2；07 libs SafeTransfer；实现时 Pool/Liquidation 加 modifier |
| **配置被任意修改** | PoolConfigurator 仅 Timelock（或指定 Admin）可调；AccessControl 校验；CONFIGURATOR 角色仅赋 Timelock | 09 §2.3；00 §7；08 §4；11 P9 |
| **升级权滥用** | ProxyAdmin 所有者为多签或 Timelock；升级走治理（12-升级流程）；不把 upgrade 权给 EOA | 09 §2.3；12 §2、§3；00 §7 |
| **清算激励不足/坏账** | 设置合理 liquidation bonus（如 5%）；closeFactor（如 50%）；监控坏账与 HF 分布；储备金/坏账路径文档化 | 09 §2.4；15 §2.C；07 Liquidation、Treasury |
| **清算逻辑资产不守恒** | 不变量测试：清算前后总供应/总借款/储备关系；单元测试覆盖边界；11 P7/P8 打勾 | 09 §2.4；11 P7/P8 |
| **利率/index 溢出或精度损失** | WadRayMath 或等价定点库（1e18/1e27）；测试边界与极端 utilization；07 libs WadRayMath | 09 §2.5；07 §2.1、§2.6 |
| **利率策略被恶意替换** | 利率策略地址仅 PoolConfigurator 可设；治理或 Admin 控制；非 Timelock 不可调 | 09 §2.5；07 PoolConfigurator；08 |
| **代理存储布局冲突** | 新实现只追加存储、不插槽不重排；升级前审查存储布局；12 回滚注意状态兼容 | 09 §2.6；12 §3、§4 |
| **初始化多次执行** | 初始化函数用 initializer 或 onlyOnce；防止重复 init；升级时 upgradeAndCall 仅一次 | 09 §2.6；12 §3.2 |
| **LTV/LT/储备因子等参数** | 由 PoolConfigurator 写入链上；链下 config（reserves.\<chainId\>.json）按环境维护；与 02 资产清单、15 §2.C 对齐 | 02 §2；15 §2.C；06 scripts/config |

- **实现时**：上述「具体避免措施」应在目标仓库 **docs/12-PROTOCOL-DESIGN.md §06**、合约注释、config 与部署脚本中写死或可配置；本文与 09 §2 为清单与索引，便于评审与打勾。
