## 七、缺口与不一致汇总

### 7.1 未实现或占位（可后续补齐）

- **FlashLoan**（07 可选）：未实现。
- **ReserveLogic.mintToTreasury**：未实现；协议收入通过 Pool reserveFactor 有效利率体现。
- **setUserUseReserveAsCollateral**：多资产时在 Pool 暴露并接 UserConfiguration；当前单资产无需。
- **DexTwapAdapter / SequencerUptimeGuard**：已占位 stub，主网/L2 时补齐实现。
- **SafeTransfer 库**：未单独封装，使用 OZ SafeERC20，与 07 命名不完全一致。

### 7.2 与文档的命名/结构差异

- **06 写 tests/**，当前目录为 **test/**：仅命名差异，子目录（unit/integration/invariants/fuzz）已齐。
- **06 要求 scripts/deploy/**：当前 **deploy.ts 在 scripts 根目录**；功能完整，若严格对齐 06 可将 deploy.ts 迁入 scripts/deploy/ 并调整 npm 脚本。
- **getNormalizedIncome/NormalizedDebt**：07 列在 ReserveLogic，当前在 **Pool** 暴露；语义一致，位置不同。

### 7.3 与升级文档的一致性结论

- **07**：核心必选项已对齐；缺口为 FlashLoan、ReserveLogic.mintToTreasury、多资产 setUserUseReserveAsCollateral、SafeTransfer 命名；Oracle 为占位可接受。
- **06**：contracts、test、scripts、liquidation-bot、monitoring、audits、formal-verification 已对齐或占位；仅 test/ vs tests/、deploy 未入子目录为小差异。
- **02**：config 驱动部署已实现；多资产为形态目标，当前单资产与 02「升级后」示例表不一致但符合 P4/P5 单资产阶段。
- **11**：P0–P8 交付物与打勾已满足；前端高标准 §10 为可选。
- **12**：§7 检查清单已在 08-deployment-runbook 中落位。
