# 迁移方案（占位）

> **用途**：当存在**主网存量**（从当前 SimpleLending 或旧版合约向代理+Pool 迁移用户/仓位数据）时，在本文档或目标仓库中展开完整迁移方案。**当前**：无主网存量，从零部署即可，本页仅作占位。

---

## 1) 何时使用本文

- **无主网存量**：直接按《12-升级流程》与目标仓库 08-deployment-runbook 做**首次部署**，无需迁移。
- **有主网存量**：需单独制定《迁移方案》，包含：存量快照、新旧合约映射、双跑/切换策略、用户通知、回滚条件。在**目标仓库**或本包内展开；本包《00-术语与约定》§8「存量迁移」已约定。

---

## 2) 占位结构（有存量时补全）

| 章节 | 内容（占位） |
|------|--------------|
| 存量范围 | 旧合约地址、区块高度、需迁移的 supply/borrow 数据与用户列表 |
| 快照与校验 | 快照时间、数据校验方式、与链上一致性检查 |
| 新池部署 | 新 Pool/代理/Configurator 部署顺序与地址 |
| 迁移策略 | 一次性迁移 vs 双跑过渡；用户资产如何从旧合约转入新池 |
| 权限与执行 | 谁可执行迁移脚本、多签/ Timelock 要求 |
| 回滚与应急 | 迁移失败或异常时的回滚条件与步骤 |
| 用户与沟通 | 公告、用户操作指引、时间窗口 |

---

## 3) 与同目录文档关系

- **01-当前项目现状**：已注明「无主网存量；若未来从主网旧合约迁移，需单独制定数据迁移与双跑方案」。
- **12-升级流程**：侧重「已有代理，换实现」；首次部署与迁移见目标仓库 08-runbook 或本文（有存量时补全）。

---
