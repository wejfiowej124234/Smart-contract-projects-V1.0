# 前端升级方案（顶级 DeFi 借贷 UI/UX：Aave/Compound/Morpho 级）

> 将当前简单借贷 Demo 前端升级为**行业顶级 DeFi 借贷**（Aave/Compound/Morpho 级）标准：信息架构与全局框架、Dashboard/Markets/Activity/Settings、**交易弹窗状态机**、风控可视化、数据与刷新、错误处理与可恢复、安全与合规 UX、本地链/Mock 专属（Dev Panel）。设计参考 Aave/Compound/Morpho 等主流协议。与《02-资产清单-抵押与借贷》《06-升级后目录结构》《08-DAO治理-设计清单》《11-升级阶段清单-P0至P10》P5/P9/P10 前端验收衔接。

## 1) 升级目标与设计参考

| 维度 | 当前（Demo） | 升级后目标 |
|------|--------------|------------|
| **整体风格** | 单页简单表单、少量卡片 | AAVE 风格：暗色主题、清晰信息层级、仪表盘式布局 |
| **数据展示** | 余额、利率等数字为主 | 增加**代币/资产分析看板**：价格、估值、部署时间、**价格+成交量波浪图**、按 DEX 分布（可选） |
| **行情图** | 无 | **波浪图**：价格折线图或 K 线图 + 成交量柱状图，时间周期切换（1d/1w/1y） |
| **多资产** | 单资产 | 多资产供应/借入列表、资产切换、健康因子与 LTV 展示 |
| **治理** | 无 | 治理 UI：提案列表、投票、执行状态（与 P9 验收对应） |
| **结构** | 单 app | frontend/app（用户 DApp）+ frontend/admin（治理/管理台），与 06 目录一致 |

**设计参考**：Aave 官网仪表盘、代币分析页（Token Price、FDV、Deployed、Price & Volume 图、Weekly Trades per DEX 等）。

## 2) 核心模块与页面结构

### 2.1 用户 DApp（frontend/app）— 对标 Aave 顶级架构

**主导航（顶部）**：Dashboard（你的组合）| Markets（市场储备）| 代币/分析 | 治理 | 更多（可选：Savings、Staking、设置）。与 Aave 的 Dashboard / Markets / Governance 对齐。

| 模块 | 说明 | 与 Aave / 波浪图对应 |
|------|------|----------------------|
| **Dashboard（你的组合）** | 总供应、总借款、健康因子、净 APY、快捷供应/借入；**你的**供应与借入列表（当前仓位） | Aave Dashboard：Portfolio Summary + 你的 Asset List |
| **Markets（市场储备）** | **市场级**：所有可供应/可借入资产；每资产 Supply APY、可用流动性、Supply caps、抵押配置；Borrow APY、可用流动性、利用率、Borrow caps；从 Markets 进入供应/借入 | Aave Markets：Reserve List、Supply/Borrow 信息、筛选与收藏 |
| **Risk & Parameters 面板** | 按资产的 LTV、清算阈值、清算奖励集中展示；可在 Dashboard 或 Markets 下折叠/展开 | Aave Risk & Parameters Panel |
| **Positions & History** | 交易历史（供应/借入/还款/取回/清算）、分页；激励领取记录（可选） | Aave Positions & History、User Activities |
| **资产/储备详情页** | 选中某资产：APY、LTV/LT/清算奖励、**该资产价格+成交量波浪图**、利率曲线、历史 APY（可选） | 详情内嵌**波浪图**，与代币看板复用组件 |
| **代币/分析看板** | 单资产或治理币：当前价、FDV、部署时间；**价格+成交量波浪图**；DEX 分布（可选） | Token Price & Volume、Weekly Trades per DEX 风格 |
| **治理入口** | 跳转治理页或展示当前提案摘要 | 与 08、P9 治理 UI 衔接 |

### 2.2 治理/管理台（frontend/admin）

| 模块 | 说明 |
|------|------|
| **提案列表** | 提案状态（Active/Pending/Executed）、投票进度、执行时间 |
| **提案详情** | 描述、投票选项、投票权、Timelock 倒计时、执行按钮 |
| **治理币/数据** | 可选：治理币价格或持仓分布（可复用波浪图组件展示治理币价格走势） |

### 2.3 波浪图组件（复用）

| 能力 | 说明 | 实现建议 |
|------|------|----------|
| **价格曲线** | 折线图（Line Chart）：时间-价格，形成「波浪」 | 图表库：Lightweight Charts / Recharts / ECharts / TradingView 等 |
| **K 线（可选）** | 蜡烛图：OHLC + 成交量，交易所风格 | 同上；TradingView 风格库或 Lightweight Charts 的 Candlestick 系列 |
| **双 Y 轴** | 左轴价格、右轴成交量；柱状图 + 折线图组合 | 与截图「Token Price & Volume」一致 |
| **时间周期** | 24h / 7d / 1y 切换 | 下拉或 Tab，驱动数据区间与聚合方式 |
| **数据源** | 链上事件 + 预言机价格；或 subgraph + 外部行情 API（DEX 历史价、成交量） | 与 06 subgraph、03 预言机设计衔接；DEX 分布可选接 The Graph / DEX 聚合 API |
| **前端降采样与视口聚合** | 数据点过多时按视口宽度或时间粒度聚合，避免主线程卡顿 | 前端请求或接收原始数据后做降采样（如 1y 按日聚合）；图表库按可见区域渲染，不一次性渲染全部点 |

## 3) UI/UX 设计要点（AAVE 风格）

| 要点 | 说明 |
|------|------|
| **暗色主题** | 主背景深色、卡片与图表对比清晰，减少长时间使用疲劳（与截图一致） |
| **信息层级** | 关键指标（价格、健康因子、APY）用大字号或高亮；次要信息收拢或折叠 |
| **波浪图位置** | 代币分析看板、资产详情页中**显著位置**；默认展示「价格+成交量」双轴图 |
| **响应式** | 移动端可简化为单列、波浪图支持横滑或缩放 |
| **无障碍** | 颜色不只依赖红绿区分涨跌；图表提供简要文字摘要（可选） |

## 5) 前端与 P0–P10 的关系及升级顺序

### P0–P10 以「后端」为主，前端嵌在 P5/P9/P10

- **P0–P10** 以**合约/链上/脚本/测试**为主（俗称「后端」）；**前端**在 **P5**（多资产 UI）、**P9**（治理 UI）、**P10**（前端集成验收）有明确集成与打勾。详见《11-升级阶段清单-P0至P10》「前端与后端顺序说明」。

### 升级顺序：先完成后端，再完成前端

- **推荐**：**按 P 先后端再前端**——每个 P 内先完成该 P 的合约与链上/脚本测试，再完成该 P 的前端集成与验收（若该 P 有前端项）。例如 P5 先完成 aToken/debtToken 合约与测试 → 再完成 P5 多资产 UI；P9 先完成 Governor/Timelock → 再完成 P9 治理 UI。
- **可选**：P0–P10 **全部**后端完成后，再集中做前端（前端排期清晰，但演示较晚）。

### 前端是否单独编号 P11–P20（可选）

- **不单独编号**：前端工作嵌在 P5/P9/P10，验收以《11-升级阶段清单-P0至P10》P5/P9/P10 打勾为准。
- **单独编号 P11–P20**：若希望前端有**独立排期与打勾**，可在 **P10 完成后** 使用 **P11–P20** 表示「前端专项阶段」；P11–P20 与本节 §10 顶级 UI/UX 清单对应，详见《11-升级阶段清单-P0至P10》「前端与后端顺序说明」中的 P11–P20 表。

## 9) 前端安全与运维

| 项 | 说明 |
|------|------|
| **XSS 与注入** | 用户输入与动态内容需转义/白名单；不将未校验数据插入 DOM。 |
| **依赖与构建** | 定期 `npm audit`；构建产物不包含敏感信息；依赖版本与 01 推荐环境一致。 |
| **钱包与 RPC** | 连接钱包仅请求必要权限；RPC 与链 ID 来自配置（环境变量或 config），不硬编码主网 key。 |
| **环境变量** | 链 ID、合约地址、公共 RPC 等可放 .env.example；敏感 key 不提交仓库（见目标仓库 08-runbook）。 |
| **Pause 时前端提示** | 协议 Pause 时（09 §4）：前端展示**全局提示**「协议已暂停」、禁用供应/借入/还款/取回等写操作、引导用户查看公告；与《09-安全设计-清单》一致。 |

**前端测试建议**（可占位）：单元测试（组件/工具函数）、E2E（关键供应/借入/治理流）；CI 中前端 lint + test 步骤见目标仓库 ci/。

## 10) 顶级 DeFi 借贷 UI/UX 清单（企业级 + 面试官标准）

以下清单对标 **Aave/Compound/Morpho** 级前端，按条打勾即可达到「企业级 + 面试官默认标准」。与 §7 验收清单一致；§7 为总览，本节为逐项可打勾明细。

### 10.1 信息架构与全局框架

- [ ] **顶部全局状态栏**：钱包连接状态 / 当前网络 / 环境标识（Mainnet / Testnet / Local）；**钱包下拉（可选，对标 Aave）**：当前账户、断开连接、复制地址、链上 explorer 链接
- [ ] **关键 KPI 区（4–6 项）**：Net Worth、Total Supply、Total Borrow、Available Borrow、Health Factor；**净 APY / Net APY（可选）**：收益−支出，与 Aave APY & Rewards 一致
- [ ] **风险提示常驻**：HF 颜色分级 + 文案（安全 / 警告 / 危险）
- [ ] **全局错误与通知系统**：Toast + 可展开详情（错误码、原因、解决建议）
- [ ] **路由结构清晰**：Dashboard / Markets / Positions / Activity / Settings（+ Dev Panel 可选，仅 Local 显示）

### 10.2 页面清单（必须有）

**Dashboard（我的仓位）**

- [ ] **未连接钱包时**：首屏显示「Connect wallet」CTA；**无仓位时**：空态插画 + Supply/Borrow 入口（与 UI-UX §4.3 空态一致）
- [ ] **Your Supplies 表**：资产、余额、价值、APY、Collateral 开关、Withdraw
- [ ] **Your Borrows 表**：资产、债务、利率模式、APY、Repay
- [ ] **Health Factor 卡**：大字、颜色、阈值说明
- [ ] **Liquidation Price（清算价）**展示（至少对主要抵押资产）
- [ ] **Borrow Power / Available Borrow**（额度条形进度条）

**Markets（市场）**

- [ ] **市场级 KPI（可选，对标 Aave）**：Total market size、Total available liquidity、Total borrows（页顶或侧栏，多市场时可按市场切换）
- [ ] **筛选**：全部 / 供应 / 借入（对标 Aave Reserve Filter，可按 Supply/Borrow 筛选储备）
- [ ] **排序（可选）**：按资产名、Supply/Borrow APY、流动性等排序
- [ ] **收藏（可选）**：收藏/Watchlist 资产，便于快速访问
- [ ] **资产列表**：Supply APY、Borrow APY、Liquidity、Utilization、风险参数（LTV / LT）；**储备 pause/freeze 状态**展示（与《09-安全设计-清单》一致，协议或单资产冻结时可见）
- [ ] **资产详情页**：利率曲线 / 利用率曲线 / 风险参数解释；储备激励（可选）
- [ ] **快捷操作**：Supply / Borrow（跳出同一套交易弹窗）

**Activity（交易历史）**

- [ ] **Tx 列表**：类型、时间、金额、状态（pending / success / fail）
- [ ] **区块浏览器链接**（本地链可链接到本地 explorer 或显示 tx hash）
- [ ] **失败原因展示 + 重试入口**

**Settings（设置）**

- [ ] **语言 / 货币单位**（USD / 原生）
- [ ] **交易保护**（默认滑点、确认策略）
- [ ] **风险偏好提示**（仅 UI，不改链上规则）

**Governance（治理，对标 Aave）**

- [ ] **提案列表**：状态（Active/Pending/Executed）、投票进度、执行时间
- [ ] **提案详情**：描述、投票选项、投票权、Timelock 倒计时、投票/执行按钮
- [ ] **创建提案（可选，admin）**：符合门槛时可在治理台提交 on-chain 提案，与《08-DAO治理-设计清单》一致
- [ ] **委托投票（可选）**：投票权委托入口与当前委托状态展示，与 08 治理币/投票权一致

### 10.3 交易弹窗（顶级 UX 的核心）

对每个动作 **Supply / Withdraw / Borrow / Repay**，统一为**状态机弹窗**：

- [ ] **输入框**：MAX、余额提示、单位切换
- [ ] **Before/After 风险预览**：HF、清算价、可借额度变化；**操作前后净收益/Net APY 变化（可选，对标 Aave）**：Repay/Withdraw 等可展示「当前→操作后」Net APY
- [ ] **费用区**：Gas 估算；**Borrow 时**：利率模式（Variable/Stable）选择与对应 APY 展示（若协议支持双模式）
- [ ] **按钮状态机**：Approve → Confirm → Pending → Success / Fail
- [ ] **Pending 中**：显示 tx hash、可取消提示（说明链上不可取消）
- [ ] **Fail 中**：错误原因（可读文案）+「如何解决」（如提高 gas / 切网络 / 余额不足）
- [ ] **Success 中**：一键返回 Dashboard + 交易详情

### 10.4 风控可视化（顶级标准）

- [ ] **Health Factor 三色分级**（绿 / 黄 / 红）+ 阈值解释
- [ ] **Borrow Power 进度条**（接近上限变黄 / 红）
- [ ] **Liquidation Price 清晰展示**（「到 X 价格会被清算」）
- [ ] **清算规则简要说明**（与 09/合约一致）：如 HF&lt;1 可被清算、清算比例上限等，可在 Dashboard 或风控面板提供入口/文案
- [ ] **利用率 Utilization 视觉化**（高利用率提示借款成本上升）
- [ ] **风险操作拦截**：当操作会把 HF 拉到危险区，弹窗必须强提醒（甚至二次确认）

### 10.5 数据与刷新体验（性能与可信）

- [ ] **UI 数据分层**：余额 / 仓位 / 市场分开拉取与缓存；**数据源建议（对标 Aave）**：市场数据与用户仓位分层拉取，可对接链上 UiPoolDataProvider 或 subgraph，避免多合约分散请求
- [ ] **乐观 UI（谨慎）**：pending 时展示「预期状态」，成功后校准
- [ ] **事件驱动刷新**：监听合约事件 / 区块更新，避免狂轮询
- [ ] **Loading Skeleton**：避免空白闪烁
- [ ] **P95 响应指标**：关键页面首屏 &lt; 1s（本地 / 测试环境）

### 10.6 错误处理与可恢复（企业级最看重）

- [ ] **统一错误映射**：RPC 错误 → 友好文案（余额不足、拒签、nonce、revert reason）
- [ ] **断网 / 节点不可用**：可见提示 + 自动重试策略
- [ ] **链切换失败**：引导用户切链（如 MetaMask 引导）
- [ ] **幂等与防重复**：按钮防抖、pending 禁用、重复提交拦截

### 10.7 安全与合规 UX（加分项）

- [ ] **风险提示**：清算风险、利率波动、合约风险免责声明
- [ ] **地址与金额展示防误读**：长地址缩略 + 复制按钮 + 二次确认
- [ ] **高风险操作二次确认**：Withdraw 全部抵押、Borrow 拉满额度
