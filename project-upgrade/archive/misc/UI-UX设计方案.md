# UI/UX 设计方案（顶级 DeFi 借贷产品级）

> 适配本升级方案的前端**顶级** UI/UX 设计：设计原则、设计系统（Design System）、信息架构、组件规范、动效与无障碍，对标 Aave / Compound / Uniswap / Lido 级产品体验。与《前端升级方案》《02-资产清单-抵押与借贷》《06-升级后目录结构》《08-DAO治理-设计清单》《11-升级阶段清单-P0至P10》P5/P9/P10 衔接。

---

## 1) 设计原则（顶级产品共识）

| 原则 | 说明 | 落地方式 |
|------|------|----------|
| **清晰优先** | 关键决策信息（健康因子、APY、清算风险）一眼可见，不藏不猜 | 仪表盘首屏即核心指标；数字层级明确（主数字 / 辅助说明） |
| **信任感** | 链上数据可验证、操作可追溯、状态可预期 | 显示数据来源（预言机/链上）；Tx 状态与链上区块链接；危险操作二次确认与倒计时 |
| **性能感知** | 首屏快、交互即时反馈、长数据骨架/渐进加载 | 骨架屏、乐观更新、图表按视口懒加载、大列表虚拟滚动 |
| **无障碍** | 键盘可达、焦点可见、色盲友好、语义化与屏幕阅读器支持 | WCAG 2.1 AA；涨跌不单靠红绿；焦点环与跳过链接；ARIA 与图表摘要 |
| **一致性** | 同一概念同一组件、同一行为同一反馈 | 设计系统 Token + 组件库；全局状态（loading/error/empty）规范 |

## 2) 设计系统（Design System）

### 2.1 设计 Token 结构

| Token 类别 | 用途 | 示例（暗色主题） |
|------------|------|------------------|
| **颜色 · 背景** | 页面 / 卡片 / 浮层层级 | `bg-page: #0d1117`；`bg-card: #161b22`；`bg-elevated: #21262d` |
| **颜色 · 表面** | 边框、分割线 | `border-default: #30363d`；`border-muted: #21262d` |
| **颜色 · 文本** | 主 / 次 / 占位 / 禁用 | `text-primary: #f0f6fc`；`text-secondary: #8b949e`；`text-muted: #6e7681` |
| **颜色 · 语义** | 成功 / 警告 / 危险 / 信息 | `success: #3fb950`；`warning: #d29922`；`danger: #f85149`；`info: #58a6ff` |
| **颜色 · 图表** | 价格线、成交量、涨跌、多系列 | `chart-up: #3fb950`；`chart-down: #f85149`；`chart-volume: #238636`（或透明度叠柱） |
| **字体** | 数字 / 标题 / 正文 / 说明 | `font-mono: 'JetBrains Mono' | 'SF Mono'`（数字）；`font-sans: 'Inter' | system-ui` |
| **字号** | 层级 | `text-display: 2rem`；`text-h1: 1.5rem`；`text-body: 0.875rem`；`text-caption: 0.75rem` |
| **字重** | 强调 | `font-normal: 400`；`font-medium: 500`；`font-semibold: 600`；`font-bold: 700` |
| **圆角** | 卡片 / 按钮 / 输入 / 标签 | `radius-sm: 4px`；`radius-md: 8px`；`radius-lg: 12px`；`radius-xl: 16px` |
| **间距** | 4px 基准网格 | `space-1: 4px` … `space-8: 32px`；`space-section: 24px` |
| **阴影** | 卡片 / 浮层 / 焦点 | `shadow-card`；`shadow-modal`；`shadow-focus`（焦点环，非纯色依赖） |

**亮色主题**：同一 Token 名，另一套取值；切换时仅换 Token，不换组件结构。

### 2.2 栅格与断点

| 断点 | 宽度 | 用途 |
|------|------|------|
| `xs` | 0–575px | 手机竖屏；单列、底部主操作 |
| `sm` | 576–767px | 手机横屏 / 小平板 |
| `md` | 768–1023px | 平板；可双列卡片 |
| `lg` | 1024–1279px | 小桌面；仪表盘 2–3 列 |
| `xl` | ≥1280px | 桌面；仪表盘 3–4 列、侧栏固定 |

- **容器**：`max-width: 1280px`（或 1440px）居中，左右 `padding` 随断点增加。
- **栅格**：12 列；卡片与图表占位按 4/6/8/12 灵活组合，保证波浪图最小宽度约 320px 可读。

### 2.3 动效规范

| 场景 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 微交互（hover/focus） | 100–150ms | ease-out | 按钮、链接、可点击卡片 |
| 面板/抽屉展开 | 200–300ms | ease-in-out | 侧栏、模态、详情滑出 |
| 页面/区块进入 | 200–400ms | ease-out | 列表渐显、数字计数动画（可选） |
| 图表数据更新 | 300–500ms | ease-out | 波浪图曲线/柱状过渡，不闪屏 |

- **减少动效**：用户偏好 `prefers-reduced-motion` 时，仅保留必要状态切换，取消装饰动画。

## 3) 信息架构与核心用户流

### 3.1 用户 DApp（frontend/app）— 对标 Aave 顶级结构

**主导航（顶部）**：Dashboard（你的组合）| Markets（市场储备）| 代币/分析 | 治理 | 更多（可选：Savings、Staking、设置）。与 Aave 的 Dashboard / Markets / Governance / Savings / Staking 对齐。

| 一级 | 二级 | 说明 | 与 Aave 对应 |
|------|------|------|--------------|
| **Dashboard** | — | **你的组合**：总供应、总借款、健康因子、净 APY、快捷供应/借入；**你的**供应与借入列表（当前仓位） | Aave Dashboard：Portfolio Summary + 你的 Asset List |
| **Markets** | 储备列表、储备详情 | **市场级**：所有可供应/可借入资产；每资产 Supply APY、可用流动性、Supply caps、抵押配置；Borrow APY、可用流动性、利用率、Borrow caps；从 Markets 进入供应/借入操作 | Aave Markets：Reserve List、Supply/Borrow 信息、筛选与收藏 |
| **资产详情** | — | 单资产：APY、LTV/LT/清算奖励、**波浪图**、利率曲线；入口可来自 Dashboard 或 Markets | Aave Reserve 详情 |
| **代币/分析** | 代币分析看板 | 价格、FDV、部署时间、**价格+成交量波浪图**、DEX 分布（可选） | 增强项（链上/行情分析） |
| **治理** | 提案列表、提案详情 | 或跳转 admin；展示当前提案摘要与入口 | Aave Governance |
| **Risk & Parameters** | — | **集中面板**（可在 Dashboard 或 Markets 下）：按资产的 LTV、清算阈值、清算奖励；与 02/03 一致 | Aave Risk & Parameters Panel |
| **Positions & History** | 交易历史、激励领取 | 供应/借入/还款/取回/清算记录；分页；激励领取记录（可选） | Aave Positions & History、User Activities |

### 3.2 治理/管理台（frontend/admin）

| 一级 | 二级 | 说明 |
|------|------|------|
| **提案** | 列表、详情、创建 | 状态筛选、投票进度、Timelock 倒计时、执行 |
| **风控/参数** | 可选 | 只读或受控参数展示；权限与 08 一致 |

### 3.3 关键用户流（简要）

- **供应**：仪表盘/资产列表 → 选资产 → 输入金额 → 授权（若需）→ 确认 → 成功/失败反馈 → 列表刷新。
- **借入**：仪表盘/资产列表 → 选资产 → 输入金额 → 健康因子预览 → 确认 → 同上。
- **查看代币/资产行情**：资产详情或代币分析 → 时间周期切换 → 波浪图与成交量更新。
- **治理**：提案列表 → 提案详情 → 投票/弃权 → 等待 Timelock → 执行（admin）。

## 4) 组件规范（核心）

### 4.1 数据展示

| 组件 | 用途 | 规范要点 |
|------|------|----------|
| **核心指标卡片** | 健康因子、总供应、总借款、APY | 大数字 + 单位 + 简短标签；危险区间用语义色+图标；可点击进入详情；**清算规则**可在 Dashboard 或风控面板提供简要说明入口（HF&lt;1 可清算、比例上限等，与 09/合约一致） |
| **数字** | 金额、利率、百分比 | 等宽字体；右对齐或统一小数位；涨跌用语义色+箭头（不单靠色）；小数位与精度见 §4.4 |
| **波浪图** | 价格+成交量 | 双 Y 轴；左价格右成交量；时间周期 Tab/下拉；hover 显示数值；提供简短文字摘要（a11y）；大数据量时前端降采样（见《前端升级方案》§2.3） |
| **表格/列表** | 资产列表、提案列表 | 表头固定（桌面）；行 hover；排序、筛选；空态与加载态统一 |

### 4.4 数字展示规范

与《02-资产清单-抵押与借贷》链上精度一致；避免前端展示与合约计算口径不一致。

| 类型 | 说明 | 建议 |
|------|------|------|
| **金额** | 供应/借入/余额等 | 小数位与资产 decimals 一致（02 与链上）；超出可读位用 K/M/B 缩写或折叠 |
| **利率（APY/APR）** | 供给利率、借款利率 | 建议 2–4 位小数；四舍五入策略统一（如 toFixed(2) 或库统一） |
| **健康因子** | HF | 建议 2 位小数；&lt;1 时高亮危险态 |
| **LTV / LT / 清算奖励** | 百分比 | 与链上 bp 或比例一致；展示时换算为百分比并统一小数位 |
| **涨跌** | 价格变化百分比 | 正负号 + 箭头 + 语义色；不单靠颜色区分 |

### 4.2 操作与反馈

| 组件 | 用途 | 规范要点 |
|------|------|----------|
| **主按钮 / 次按钮** | 确认、取消、主要操作 | 主按钮高对比；加载中禁用+loading 图标；危险操作用 danger 变体 |
| **输入框** | 金额、地址 | 单位与最大可操作量展示；错误态与帮助文案；键盘可操作 |
| **模态/抽屉** | 确认交易、授权、二次确认 | 焦点陷阱；Esc 关闭；关闭后焦点回退 |
| **Toast/通知** | 交易结果、错误、网络状态 | 自动消失+可关闭；不遮挡关键操作区；支持屏幕阅读器 |

### 4.3 全局状态

| 状态 | 表现 | 说明 |
|------|------|------|
| **Loading** | 骨架屏 / 区块 spinner / 按钮 loading | 首屏用骨架；按钮用内联 loading；避免整页白屏 |
| **Empty** | 插画+文案+主操作 | 无仓位、无提案、无搜索结果等 |
| **Error** | 文案+重试/反馈入口 | 网络错误、合约 revert、权限不足等 |
| **Success** | 简短确认+可选跳转 | 交易成功、投票成功等 |

## 5) 页面级布局（顶级标准）

### 5.1 仪表盘（首屏）

- **上**：导航（Logo、主导航、**钱包连接**（可选下拉：当前账户、断开、复制地址、explorer 链接）、网络切换）。
- **未连接钱包时**：首屏显示 **「Connect wallet」** CTA；无仓位时显示空态插画 + Supply/Borrow 入口（与 §4.3 空态一致）。
- **中上**：3–4 张核心指标卡片（总供应、总借款、健康因子、**净 APY / Net APY（可选，对标 Aave）**）；健康因子低于阈值时卡片高亮。
- **中**：快捷操作（供应/借入入口）+ 最近资产或活跃提案摘要。
- **下**：**你的**供应/借入列表（当前仓位）；支持按 APY、余额排序；可折叠 **Risk & Parameters**（按资产的 LTV、LT、清算奖励）。
- **下或独立 Tab**：**Positions & History** — 交易历史（供应/借入/还款/取回/清算）、分页；激励领取记录（可选）。
- **响应式**：移动端单列；指标卡片可横滑；主操作固定底部或吸底。

### 5.2 Markets（市场储备）

- **上**：网络切换、筛选（全部/供应/借入）、收藏（可选）；**市场级 KPI（对标 Aave，可选）**：Total market size、Total available liquidity、Total borrows（多市场时可按市场切换）。
- **主区**：储备列表 — 每行/卡片：资产、Supply APY、可用流动性、Supply caps（可选）、Borrow APY、可用流动性、利用率、Borrow caps（可选）、抵押开关、**储备 pause/freeze 状态**（与 09 一致）；点击进入储备详情或直接供应/借入。
- **储备详情**：与 §5.3 资产详情一致（APY、LTV/LT/清算奖励、波浪图、主操作）；若协议支持 flash loan、eMode，在详情或列表中按需展示（见《前端升级方案》§10.2）。

### 5.3 代币/资产分析看板

- **上**：面包屑 + 资产选择器（或单资产标题）；当前价、FDV、部署时间等摘要卡片。
- **主区**：**价格+成交量波浪图**（折线或 K 线 + 柱状）；时间周期 24h/7d/1y；图例与单位清晰。
- **下或侧**：按 DEX 分布（可选）、该资产在协议内的供应/借入占比（可选）。
- **无障碍**：图表区域提供「近期价格与涨跌」文字摘要；焦点可进入图表并支持键盘切换周期。

### 5.4 资产详情

- **上**：资产标识、当前 APY、清算阈值、LTV；主操作（供应/借入/还款/取回）。
- **中**：**该资产价格+成交量波浪图**（与代币看板复用组件）。
- **下**：利率曲线说明、历史 APY（可选）、风险提示。

### 5.5 治理（提案列表 / 详情）

- **列表**：状态 Tag（Active/Pending/Executed）、标题、投票进度条、截止/执行时间；筛选与排序。
- **详情**：描述、参数变更摘要、投票选项与当前票数、Timelock 倒计时、投票/执行按钮；状态清晰（待投票/待执行/已执行）。
- **创建提案（可选，admin）**：符合门槛时在治理台提交 on-chain 提案，与《前端升级方案》§10.2 Governance 一致。
- **委托投票（可选）**：投票权委托入口与当前委托状态展示，对标 Aave；与《08-DAO治理-设计清单》一致。

### 5.6 移动端专属交互

| 项 | 说明 |
|------|------|
| **底部主导航** | 移动端用底部 Tab/导航：仪表盘、资产、代币分析、治理；主操作（供应/借入）可吸底或浮动按钮 |
| **列表下拉刷新** | 供应/借入列表、提案列表支持下拉刷新，更新链上数据 |
| **波浪图横滑** | 小屏下波浪图支持横滑查看历史区间，或时间周期 Tab 切换；避免一次渲染过多点（配合降采样） |
| **空态与加载态** | 无仓位、无提案时移动端专属空态插画+文案+主操作；加载用骨架与列表占位一致 |

## 6) 无障碍（WCAG 2.1 AA 级）

| 要求 | 落地 |
|------|------|
| **对比度** | 正文与背景 ≥4.5:1；大字 ≥3:1；交互元素与背景 ≥3:1 |
| **焦点** | 所有可交互元素可键盘到达；焦点环明显（shadow-focus），不依赖纯色 |
| **涨跌** | 用图标/箭头+文字（涨/跌），不单靠红绿；或提供「涨跌」开关 |
| **图表** | 波浪图提供简短文字摘要（如「过去 7 天价格从 x 到 y，涨幅 z%」）；或可聚焦数据点读屏 |
| **表单** | 标签与错误与输入关联（label/aria-describedby）；必填与错误态明确 |
| **跳过链接** | 主内容前提供「跳到主内容」链接 |

## 7) 性能与体验

| 项 | 建议 |
|------|------|
| **首屏** | 关键指标与列表骨架优先；图表按需懒加载 |
| **列表** | 长列表虚拟滚动（如 100+ 行） |
| **图表** | 数据点过多时降采样或按视口聚合；避免主线程长时间阻塞 |
| **网络** | 请求失败重试与明确错误态；链切换时清空依赖链上的状态 |

## 9) 交付物建议（设计阶段）

- **Design Token 表**：颜色/字体/间距/圆角/阴影（**暗色必选**；亮色可选或与暗色同步交付）。
- **组件库**：核心指标卡片、按钮、输入、表格、波浪图、模态、Toast 等；含状态（默认/hover/焦点/禁用/错误）。
- **关键页面线框图或高保真**：仪表盘、代币分析看板、资产详情、治理列表与详情。
- **无障碍检查清单**：基于 WCAG 2.1 AA 的自检项（对比度、焦点、图表摘要、表单）。
- **数字展示规范**：见 §4.4；金额/利率与 02 资产 decimals 一致；健康因子、APY 小数位与四舍五入策略统一。

| **Markets** | 市场储备列表：每资产 Supply APY、可用流动性、Supply caps、抵押配置；Borrow APY、可用流动性、利用率、Borrow caps；筛选、收藏；储备详情（flash loan、pause/freeze、eMode 等） |

### 10.3 仍需实现时落实的项

- **Testnet 模式**：在全局设置（如右上角）提供「主网 / 测试网」切换，RPC 与链 ID 与 01 环境表一致。
- **Savings / Staking**：若协议后续支持 sToken、质押等，可像 Aave 一样增加一级导航；当前为可选。
- **储备详情扩展**：flash loan、**pause/freeze 状态**、eMode（若协议支持）等在储备详情或 Markets 列表中按需展示，与 07/09 合约清单一致；见《前端升级方案》§10.2。
- **市场级 KPI**：Markets 页可选展示 Total market size、Total available liquidity、Total borrows（对标 Aave）；多市场时市场标识（name、chain、address）占位。
- **借入利率模式**：Borrow 弹窗内若协议支持 Variable/Stable 双模式，需提供选择与对应 APY 展示；见《前端升级方案》§10.3。
- **数据层**：市场数据与用户仓位分层拉取，可对接 UiPoolDataProvider 或 subgraph，与《前端升级方案》§10.5 一致。
- **净 APY / Net APY**：Dashboard 关键 KPI 区可选展示净 APY（收益−支出）；交易弹窗 Before/After 可选展示「操作前后 Net APY 变化」（对标 Aave），见《前端升级方案》§10.2–§10.3。
- **钱包下拉与空态**：顶部钱包区域可选下拉（账户、断开、复制地址）；未连接时 Dashboard 显示 Connect wallet CTA；见《前端升级方案》§10.1、§10.2。
