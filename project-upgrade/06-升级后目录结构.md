## 6) 与「升级后目标形态」对比

| 目录/维度   | 当前真实（本仓） | 行业目标形态（可选扩展） |
|------------|------------------|---------------------------|
| **contracts/** | core/tokens/oracle/governance/libs/interfaces/mocks/test + 根目录 SimpleLending.sol、ImportProxy.sol；无独立 upgrade/、crosschain/ | 可增加 upgrade/、crosschain/ |
| **test/**      | unit/、integration/、invariants/、fuzz/；无 fork/、mocks/ 子目录 | 可增加 fork/、test/mocks/ |
| **scripts/**   | deploy/、config/、governance/、ci/、security-gate/、release/、demo/、ops/、verify/、_lib；根目录 smoke-e2e.mjs、run-liquidation-bot.ts | 与目标形态已高度一致 |
| **链下**       | 无 subgraph/、keeper-bots/；清算为 scripts/run-liquidation-bot.ts | subgraph/、liquidation-bot/、keeper-bots/ |
| **审计/监控**  | docs/archive/audits/；无独立 audits/、monitoring/ 目录 | audits/、monitoring/ |
| **CI**         | .github/workflows/ci.yml 单文件 | 可拆为 ci/ 多 workflow |
| **frontend/**  | 单层 src/（pages/components/hooks/state/config 等），无 app/、admin/ 分目录 | app/、admin/、shared/ |

**结论**：当前仓库目录已与「真实代码」一致，核心模块划分清晰；与《00-与当前代码对齐说明》§2.3 一致。上表右侧为后续可选的扩展形态，非必须。

详见《01-当前项目现状》《11-升级阶段清单-P0至P10》。
